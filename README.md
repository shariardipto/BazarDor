# 🛒 বাজার দর — Bazar Dor

বাজার দর একটি আধুনিক বাজারদর তথ্যভিত্তিক ওয়েব অ্যাপ্লিকেশন, যেখানে ব্যবহারকারীরা বিভিন্ন প্রয়োজনীয় পণ্যের বর্তমান দাম, দামের পরিবর্তন এবং বাজারভিত্তিক বিস্তারিত তথ্য দেখতে পারেন।

## ✨ Key Features

1. বিভিন্ন ক্যাটাগরির বাজারদর এক নজরে দেখা যায়।
2. আজ দাম বেড়েছে ও কমেছে এমন পণ্য আলাদাভাবে দেখা যায়।
3. দাম কম থেকে বেশি অথবা বেশি থেকে কম অনুযায়ী পণ্য sort করা যায়।
4. BetterAuth ব্যবহার করে Email/Password, Google এবং GitHub authentication রয়েছে।
5. Product Details page protected — শুধুমাত্র logged-in user দেখতে পারে।
6. প্রতিটি পণ্যের সর্বনিম্ন, সর্বাধিক ও গড় মূল্য দেখা যায়।
7. বিভিন্ন বাজারভিত্তিক পণ্যের বিস্তারিত মূল্য দেখা যায়।
8. User Profile এবং নাম update করার সুবিধা রয়েছে।
9. Loading skeleton, toast notification এবং custom 404 page রয়েছে।
10. Mobile, Tablet এবং Desktop responsive design।
